# 用户协议后台管理系统

## 概述

用户协议后台管理系统是命运塔游戏的法务合规管理工具，支持多语言用户协议的可视化编辑、版本管理和一键发布。

## 系统功能

### 1. 多语言版本管理
- 支持15种语言的用户协议管理
- 实时切换不同语言版本
- 各语言版本独立管理

### 2. 可视化编辑器
- 富文本编辑功能
- 章节管理（添加、删除、排序）
- 实时预览（手机/桌面端）

### 3. 文件上传
- 支持 HTML、Markdown、TXT 格式
- 拖拽上传
- 批量导入

### 4. 版本控制
- 版本历史记录
- 一键回滚
- 发布状态管理

### 5. 发布管理
- 草稿模式
- 一键发布
- 用户强制更新提示

## 操作流程

### 1. 编辑现有协议

1. 在左侧语言列表中选择要编辑的语言
2. 在编辑器区域修改内容
3. 点击"💾 保存草稿"
4. 在右侧预览区域查看效果
5. 确认无误后点击"🚀 发布"

### 2. 上传新版本

1. 点击顶部"📤 上传新版本"按钮
2. 选择目标语言
3. 输入版本号（如：1.1）
4. 选择或拖拽文件上传
5. 点击"确认上传"
6. 系统会自动解析并生成可编辑的章节

### 3. 发布新协议

1. 确认当前版本内容无误
2. 点击"🚀 发布当前版本"
3. 确认发布提示
4. 发布后所有新用户将看到最新版本
5. 已登录用户将在下次启动时收到更新提示

### 4. 回滚历史版本

1. 在编辑器底部查看"历史版本"列表
2. 找到要回滚的版本
3. 点击"回滚"按钮
4. 确认回滚操作
5. 回滚后当前内容将被替换为历史版本

```http
{
```

```http
}
```

### 上传文件

```http

Authorization: Bearer {token}
Content-Type: multipart/form-data

- file: (binary)
```

```http
Authorization: Bearer {token}
```

```javascript
}
```

## 版本管理规则

### 版本号规范

采用语义化版本控制（SemVer）：

```
主版本号.次版本号.修订号
 1    .    0    .   0
```

- **主版本号**：重大更新，需要用户重新同意
- **次版本号**：功能新增，建议用户查看
- **修订号**：bug修复，静默更新

### 发布流程

```
草稿编辑 → 保存草稿 → 预览测试 → 发布上线 → 用户可见
```

### 用户提示策略

| 版本变化 | 用户提示 |
|---------|---------|
| 主版本号变化 | 强制弹窗，必须重新同意 |
| 次版本号变化 | 启动时显示更新提示 |
| 修订号变化 | 静默更新，不提示 |

## 常见问题

### Q: 如何添加新语言？
A: 联系技术团队添加语言配置，然后按照现有流程创建协议内容。

### Q: 发布后能否立即撤回？
A: 可以，使用"回滚"功能可立即恢复到上一版本。

### Q: 用户不同意协议怎么办？
A: 用户必须同意协议才能继续使用游戏，不同意将退出游戏。

### Q: 如何测试协议显示效果？
A: 使用右侧预览功能，可在手机和桌面视图间切换。

### Q: 协议内容有字数限制吗？
A: 建议单个章节不超过5000字，总长度不超过50000字。
