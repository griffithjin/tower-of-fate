# 命运塔 Tower of Fate - 正式版

🎮 **一款基于 Three.js 的 3D 卡牌策略游戏**

## 🎯 游戏特色

### P0 - 核心游戏逻辑 ✅
- **守卫牌系统**: 13个守卫，每个13张牌+3张激怒牌
- **匹配逻辑**: 点数+花色都匹配=+2层，点数或花色匹配=+1层
- **激怒牌系统**: 39张激怒牌（13层×3），触发则回退
- **首登者机制**: 首位到达13层玩家成为首登者，变身最高层守卫
- **手牌系统**: 52张手牌横滑显示，选中效果，出牌动画

### P1 - 视觉优化 ✅
- **3D塔模型**: 13层立体塔，每层不同颜色
- **头像系统**: 50个Avatar，支持多玩家显示
- **音效系统**: Web Audio API实现出牌、匹配、激怒等音效
- **UI优化**: 响应式布局，移动端适配

### P2 - 增强体验 ✅
- **动画效果**: 3D卡牌飞行动画、爬楼粒子效果
- **AI对手**: 3个AI玩家，自动对战

## 🎮 游戏规则

### 基本规则
- 52张手牌，13层塔楼需要攀登
- 每层有对应的守卫和3张激怒牌
- 打出卡牌与守卫牌匹配来爬升

### 匹配规则
- **完美匹配** (点数+花色): 上升2层
- **部分匹配** (点数或花色): 上升1层
- **不匹配**: 停留，检查激怒牌

### 激怒牌
- 13层每层3张，共39张
- 如果打出的卡牌与激怒牌匹配，回退1层

### 胜利条件
- 首位到达A层（第13层）的玩家获胜
- 成为首登者可变身为最高层守卫

## 🛠️ 技术栈

- **Three.js**: 3D渲染引擎
- **WebGL**: 硬件加速3D图形
- **Web Audio API**: 音效系统
- **CSS3**: 动画和UI
- **ES6+**: 现代JavaScript
